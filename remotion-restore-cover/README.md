A seamless four-second before-and-after comparison loop for the app's old
photo restoration feature. The left side shows the original photo and the
right side shows the restored photo.

## Commands

Install dependencies:

```console
npm i
```

Preview in Remotion Studio:

```console
npm run dev
```

Render the production MP4:

```console
npm run render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
